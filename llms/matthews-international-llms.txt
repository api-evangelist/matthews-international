# Matthews International

> Matthews International Corporation (NASDAQ: MATW) is a Pittsburgh, Pennsylvania

## APIs

Matthews International publishes no public API. No developer portal, API reference, API
documentation, SDK, package, CLI, MCP server, A2A agent card, Postman collection or
machine-readable specification (OpenAPI, Swagger, AsyncAPI, GraphQL SDL, JSON Schema)
was found on any host the company controls. There is no GitHub organization.

The `api.matw.com` and `developer.matw.com` hosts previously recorded against this
company were scaffold values that never existed — both are NXDOMAIN — and were removed
from `apis.yml` on 2026-08-13.

The closest thing to an integration surface is the MPERIA controller sold with Matthews
Marking Systems equipment. Matthews markets it as offering "a single user interface and
common API" for controlling Matthews and third-party marking technologies and for
integrating ERP, WMS, MES and PLC systems without middleware. In practice that is an
on-premises device protocol — XML or a command-line protocol carried over Ethernet or
RS-232, with VNC for remote management — documented in product datasheets and sales
collateral rather than in a public developer reference. It is not addressable over the
internet and has no published specification.

## Notes

- Portfolio changes matter for anyone looking for a Matthews software surface. The
  warehouse automation business — Matthews Automation Solutions, with the Pyramid, Compass
  and Lightning Pick WES/WCS software brands — was sold to Duravant on 31 December 2025, so
  `matthewsautomation.com` is no longer a Matthews property. The majority of the SGK brand
  business was contributed to Propelis Group on 1 May 2025, leaving Matthews with a 40%
  interest, so `sgkinc.com` is likewise not a Matthews-controlled surface. Any API found on
  those hosts belongs to another company and must not be attributed to Matthews.
